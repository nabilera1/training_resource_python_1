# 텍스트 게임 프로젝트를 구현하며 배우는 파이썬 프로그래밍

업다운·가위바위보·숫자 야구·행맨·던전 탈출 같은 **텍스트 게임**을 직접 분석하고 고쳐 보며 파이썬의 기초를 익히고, 마지막에는 **클래스로 만든 핑퐁(pygame) 게임**과 **나만의 게임 프로젝트**로 마무리하는 고등학교 「정보」 '알고리즘과 프로그래밍' 단원 수업 자료입니다. 22차시 동안 **문제 발견 → 문제 구조화 → 컴퓨팅 설계 → 구현 → 테스트 및 개선 → 공유·확장**의 6단계 문제 해결 모형을 따라갑니다. 모든 차시에 학습 목표, 핵심 코드 설명, 실습, 퀴즈, 코딩 테스트(정답·해설), 학생 활동지, 학습용 PPT가 있습니다.

## 대상과 구성

- 대상: 고등학교 1학년 「정보」 수강생, 파이썬 입문자, 정보 교사(수업·연수용)
- 분량: 22차시 (1부 1~4 · 2부 5~7 · 3부 8~12 · 4부 13~17 · 5부 18~22) + 부록
- 환경: Python 3.10 이상, pygame 2.5 이상 (4부부터)

| 차시 | 부 | 6단계 | 제목 | 게임 |
| --- | --- | --- | --- | --- |
| 1 | 1부 | 문제 발견 | 놀이 속 알고리즘 찾기 | 업다운 · 가위바위보 · 기억력 게임 체험 |
| 2 | 1부 | 문제 구조화 | 게임 데이터 추상화: 변수·자료형·입력 | 업다운 게임의 데이터 찾기 |
| 3 | 1부 | 문제 구조화 | 규칙 분해와 조건문 | 업다운 판정 · 가위바위보 판정 |
| 4 | 1부 | 컴퓨팅 설계 | 순서도와 while 반복문: 업다운 완성 | 업다운 게임 (기본 버전) |
| 5 | 2부 | 컴퓨팅 설계 | 리스트와 random: 가위바위보 | 가위바위보 (기본 버전) |
| 6 | 2부 | 컴퓨팅 설계 | for 반복문과 문자열: 숫자 야구 | 숫자 야구 (기본 버전) |
| 7 | 2부 | 컴퓨팅 설계 | 리스트 누적·비교와 문자열 메서드: 기억력 게임 | 기억력 게임 (기본 버전) |
| 8 | 3부 | 구현 | 함수로 나누기: 업다운·기억력 게임 함수 버전 | 업다운 (함수 버전) · 기억력 게임 (함수 버전) |
| 9 | 3부 | 구현 | 딕셔너리: 규칙을 데이터로 표현하기 | 가위바위보 (함수 버전) |
| 10 | 3부 | 구현 | 2차원 리스트와 중첩 반복: 판정표와 기록표 | 가위바위보 판정표 버전 |
| 11 | 3부 | 구현 | 종합 실습: 영단어 행맨 | 영단어 행맨 (난이도 중) |
| 12 | 3부 | 구현 | 심화: 던전 탈출과 BFS 탐색 | 던전 탈출 (난이도 상) |
| 13 | 4부 | 구현 | 클래스와 객체: 붕어빵 틀로 게임 요소 만들기 | 핑퐁 게임 미리 보기 · Paddle 클래스 읽기 |
| 14 | 4부 | 구현 | pygame 게임 루프: 입력 → 업데이트 → 그리기 | 핑퐁 1단계 (step1_game_loop.py) · main.py · game.py |
| 15 | 4부 | 구현 | Paddle 클래스: 키 입력과 경계 처리 | 핑퐁 2단계 (step2_paddle_class.py) · paddle.py |
| 16 | 4부 | 구현 | Ball 클래스: 속도 벡터·반사·충돌 | 핑퐁 3단계 (step3_ball_bounce.py) · ball.py |
| 17 | 4부 | 구현 | Scoreboard와 Game: 점수·승패·재시작으로 완성하기 | 핑퐁 완성본 (main.py · game.py · scoreboard.py) |
| 18 | 5부 | 테스트 및 개선 | 테스트 케이스로 오류 찾고 개선하기 | 업다운 개선 버전 (11_updown_safe.py) · 핑퐁 테스트 |
| 19 | 5부 | 공유·확장 | 나만의 게임 프로젝트 기획과 설계 | 프로젝트 계획서 · 순서도 · 클래스 구조도 |
| 20 | 5부 | 공유·확장 | 프로젝트 구현: 설계대로 만들고 기능 확장하기 | 확장 예제: 공 가속 · AI 패들 · 최고 기록 저장 |
| 21 | 5부 | 공유·확장 | 프로젝트 테스트·리팩터링과 차트 작성 | 동료 테스트 · 코드 리뷰 체크리스트 · 최종 차트 |
| 22 | 5부 | 공유·확장 | 게임 시연·발표와 프로젝트 성찰 | 갤러리 워크 · 발표 · 동료 평가 · 위키독스/깃허브 공유 |

