## 6단계 문제 해결 수업 모형

이 책의 22차시는 하나의 큰 문제 해결 과정입니다. 차시마다 중심이 되는 단계가 있지만, 각 차시 안에서도 '질문 → 설계 → 구현 → 확인'이 작게 반복됩니다.

| 단계 | 차시 | 하는 일 |
| --- | --- | --- |
| 문제 발견 | 1 | 놀이(게임) 속에서 컴퓨터로 해결할 문제를 찾고 입력–처리–출력으로 분석 |
| 문제 구조화 | 2~3 | 필요한 데이터를 추상화하고, 규칙을 하위 문제로 분해 |
| 컴퓨팅 설계 | 4~7 | 순서도·의사코드로 반복·분기를 설계하고 리스트·문자열로 기본 게임 구현 |
| 구현 | 8~17 | 함수·딕셔너리·2차원 리스트(텍스트 게임) → 클래스·모듈(핑퐁 게임)로 구현 |
| 테스트 및 개선 | 18 | 정상·경계·예외 테스트 케이스로 오류를 찾고 입력 검증·함수 분리로 개선 |
| 공유·확장 | 19~22 | 나만의 게임 확장 프로젝트(기획→구현→테스트→발표)로 6단계를 스스로 다시 적용 |

```text
 문제 발견 → 문제 구조화 → 컴퓨팅 설계 → 구현 → 테스트 및 개선 → 공유·확장
    1          2~3          4~7        8~17        18           19~22
                                                       └── 확장 프로젝트에서 6단계를 다시 한 바퀴
```
