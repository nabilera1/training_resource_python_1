> **3부 함수와 자료구조로 게임 다듬기** · 10차시 · 6단계 모형: **구현**  
> 게임: 가위바위보 판정표 버전  
> 핵심 개념: 2차원 리스트, 행, 열, 중첩 반복, enumerate, 튜플 반환

## 학습 목표

1. 2차원 리스트를 만들고 [행][열] 인덱싱으로 값을 읽을 수 있다.
2. 중첩 반복문으로 표 형태의 데이터를 처리하고 출력할 수 있다.
3. 게임 규칙(판정표)과 기록(기록표)을 2차원 리스트로 모델링할 수 있다.

## 핵심 질문

> **표(행과 열)로 된 규칙과 기록은 어떤 자료구조에 담아야 할까?**

3차시에 그린 가위바위보 판정 표를 기억하나요? 행은 '나', 열은 '컴퓨터'인 3 × 3 표였습니다.
이 표를 **그대로 코드로 옮긴 것이 2차원 리스트**입니다. 경기 기록(라운드, 나, 컴퓨터, 결과)도 한 줄씩 쌓이는 표이므로 2차원 리스트로 저장할 수 있습니다.

## 2차원 리스트 = 리스트 안의 리스트

```python
TABLE = [[0, 2, 1],   # 0행 나: 가위
         [1, 0, 2],   # 1행 나: 바위
         [2, 1, 0]]   # 2행 나: 보
#        가위 바위 보  ← 열: 컴퓨터

print(TABLE[1])       # [1, 0, 2]  ← 1행 전체
print(TABLE[1][0])    # 1          ← 1행 0열 (나 바위, 컴퓨터 가위 → 이김)
print(len(TABLE), len(TABLE[0]))   # 3 3  (행 개수, 열 개수)
```

**첫 번째 [ ]는 행, 두 번째 [ ]는 열**입니다. 순서를 바꾸면 결과가 반대가 되니 주의하세요!

## 판정표로 승패 구하기

```python
RESULT_TEXT = ["비김", "이김", "짐"]

def play_match(win_goal=2):
    score = {"이김": 0, "짐": 0, "비김": 0}
    records = []                                      # 기록표 (2차원 리스트)
    while score["이김"] < win_goal and score["짐"] < win_goal:
        me, cpu = get_pick(), random.randrange(3)     # 둘 다 인덱스(0~2)
        result = RESULT_TEXT[TABLE[me][cpu]]          # 표에서 찾기 → 문구
        score[result] += 1
        records.append([len(records) + 1, CHOICES[me], CHOICES[cpu], result])
    return records, score["이김"] == win_goal         # 값 2개 반환 (튜플)
```

`return a, b`처럼 쓰면 값 두 개를 묶어서(튜플) 돌려주고, `records, won = play_match()`로 나눠 받을 수 있습니다.

## 중첩 반복으로 기록표 출력

```python
def print_records(records):
    for row in [["라운드", "나", "컴퓨터", "결과"]] + records:   # 바깥: 행
        for item in row:                                       # 안쪽: 칸
            print(f"{item!s:<5}", end="| ")
        print()                                                # 행이 끝나면 줄 바꿈
```

```text
라운드  | 나    | 컴퓨터  | 결과   | 
1    | 바위   | 가위   | 이김   | 
2    | 보    | 보    | 비김   | 
```

- `:<5` : 5칸 너비로 왼쪽 정렬, `end="| "` : 줄을 바꾸지 않고 `| `로 끝냄
- 안쪽 반복이 한 번 다 돌 때마다 바깥 반복이 한 번 진행됩니다. 3행 × 4칸이면 print는 12번 + 줄 바꿈 3번

## 확장: 딕셔너리 규칙으로 판정표 자동 만들기

가위·바위·보·도마뱀·스팍 5가지로 늘리면 판정표는 5 × 5 = 25칸입니다. 손으로 쓰면 실수하기 쉬우므로, **규칙은 딕셔너리에만 적고 판정표는 중첩 반복문으로 만듭니다.** (`12_rpsls_table.py`)

```python
CHOICES = ["가위", "바위", "보", "도마뱀", "스팍"]
BEATS = {"가위": ["보", "도마뱀"], "바위": ["가위", "도마뱀"],   # 이기는 쪽: [지는 쪽 2개]
         "보": ["바위", "스팍"], "도마뱀": ["스팍", "보"], "스팍": ["가위", "바위"]}

def make_table(choices, beats):
    table = []
    for me in choices:              # 바깥 반복: 행(나)
        row = []
        for cpu in choices:         # 안쪽 반복: 열(컴퓨터)
            if me == cpu:
                row.append(0)       # 비김
            elif cpu in beats[me]:
                row.append(1)       # 이김
            else:
                row.append(2)       # 짐
        table.append(row)           # 한 행 완성 → 표에 추가
    return table
```

| 줄 | 설명 |
| --- | --- |
| `for me in choices` | 행을 하나씩 만든다. 행 = 내가 낸 것 |
| `row = []` | 새 행을 빈 리스트로 시작 |
| `for cpu in choices` | 그 행의 칸을 왼쪽부터 채운다. 열 = 컴퓨터가 낸 것 |
| `cpu in beats[me]` | 딕셔너리 값(리스트) 안에 컴퓨터 선택이 있으면 내가 이김 |
| `table.append(row)` | 완성된 행을 표에 붙인다 → 5번 반복하면 5 × 5 표 |

`python 12_rpsls_table.py test`로 실행하면 '모든 쌍에서 한쪽이 이기면 다른 쪽은 진다(대칭성)'를 `assert`로 자동 검사하고 판정표를 출력합니다.

### 08_rps_table.py

```python
"""가위바위보 판정표 버전 - 10차시: 2차원 리스트, 중첩 반복문, 딕셔너리, 함수

실행 방법: python 08_rps_table.py
"""

# =====================================================================
# 2차원 리스트 = "리스트 안에 리스트" = 표(행과 열)
#
#   판정표 TABLE[나][컴퓨터]  (0 비김, 1 이김, 2 짐)
#                 컴퓨터: 가위  바위  보
#     나: 가위 (0)      [  0,   2,   1 ]
#     나: 바위 (1)      [  1,   0,   2 ]
#     나: 보   (2)      [  2,   1,   0 ]
#
#   TABLE[1][0] → 1행 0열 → 나 바위, 컴퓨터 가위 → 1(이김)
#   ※ 첫 번째 [ ] 는 행(나), 두 번째 [ ] 는 열(컴퓨터). 순서를 바꾸면 결과가 반대가 돼요!
#
# 기록표 records 도 2차원 리스트예요.
#   [[1, "바위", "가위", "이김"],
#    [2, "보",   "보",   "비김"], ...]
#   → 중첩 for 문으로 행을 하나씩, 그 안에서 칸을 하나씩 출력해요.
# =====================================================================

import random

CHOICES = ["가위", "바위", "보"]
# 판정표: TABLE[나][컴퓨터] → 0 비김, 1 이김, 2 짐 (if문 대신 표로 규칙을 모델링)
TABLE = [[0, 2, 1],   # 나: 가위
         [1, 0, 2],   # 나: 바위
         [2, 1, 0]]   # 나: 보
RESULT_TEXT = ["비김", "이김", "짐"]

def get_pick():
    """올바른 선택(가위/바위/보)이 들어올 때까지 다시 묻고, 인덱스를 돌려준다"""
    while True:
        pick = input("가위 / 바위 / 보 > ").strip()   # strip(): 앞뒤 공백 제거 ("가위 " → "가위")
        if pick in CHOICES:
            return CHOICES.index(pick)
        print("가위, 바위, 보 중에서 입력하세요!")

def play_match(win_goal=2):
    """먼저 win_goal승 하면 끝나는 한 경기. 기록표(2차원 리스트)와 승리 여부를 돌려준다"""
    score = {"이김": 0, "짐": 0, "비김": 0}
    records = []                      # [[라운드, 나, 컴퓨터, 결과], ...]
    while score["이김"] < win_goal and score["짐"] < win_goal:
        me, cpu = get_pick(), random.randrange(3)   # randrange(3): 0, 1, 2 중 하나
        result = RESULT_TEXT[TABLE[me][cpu]]        # 표에서 값 찾기 → 문구로 변환
        score[result] += 1
        # 한 라운드 = 한 행(리스트)을 기록표 맨 뒤에 추가
        records.append([len(records) + 1, CHOICES[me], CHOICES[cpu], result])
        print(f"나: {CHOICES[me]} vs 컴퓨터: {CHOICES[cpu]} → {result}")
    # 값 2개를 한 번에 돌려줌 (튜플). 받는 쪽: records, won = play_match()
    return records, score["이김"] == win_goal

def print_records(records):
    """기록표를 중첩 반복문으로 출력한다"""
    # 바깥 for: 행(라운드) 하나씩 / 안쪽 for: 그 행의 칸 하나씩
    for row in [["라운드", "나", "컴퓨터", "결과"]] + records:   # 머리글 행 + 기록 행들
        for item in row:
            # :<5 → 5칸 너비로 왼쪽 정렬, end="| " → 줄을 바꾸지 않고 "| "로 끝냄
            print(f"{item!s:<5}", end="| ")
        print()                                                  # 한 행이 끝나면 줄 바꿈

def main():
    print("=== 가위바위보 === 먼저 2승 하면 이깁니다!")
    while True:
        records, won = play_match()
        print_records(records)
        print("최종 승리!" if won else "아쉽게 패배...")
        # .strip().lower(): 공백 제거 + 소문자로 → "Y", " y " 도 모두 "y" 로 인정
        if input("또 할까요? (y/n) > ").strip().lower() != "y":
            break

if __name__ == "__main__":
    main()
```

### 12_rpsls_table.py

```python
"""5가지 가위바위보 (산출물 예시) - 딕셔너리 → 2차원 판정표 자동 생성, 기록표, 함수, 자동 테스트

실행 방법: python 12_rpsls_table.py
자동 테스트: python 12_rpsls_table.py test
"""

# =====================================================================
# 08_rps_table.py(3가지)를 5가지 규칙으로 확장한 예시예요.
#   가위 · 바위 · 보 · 도마뱀 · 스팍  (각 선택은 다른 2개를 이기고, 2개에게 져요)
#
# 3가지일 때는 판정표 TABLE 을 손으로 9칸 썼지만, 5가지면 25칸!
# → 규칙은 딕셔너리 BEATS 에 "누가 누구를 이기나"만 적고,
#   판정표(2차원 리스트)는 중첩 반복문으로 자동으로 만들어요.
#   이렇게 하면 규칙이 바뀌어도 BEATS 한 곳만 고치면 됩니다.
# =====================================================================

import random
import sys

CHOICES = ["가위", "바위", "보", "도마뱀", "스팍"]
# 이기는 쪽: [지는 쪽 2개]  (딕셔너리의 값이 리스트)
BEATS = {
    "가위": ["보", "도마뱀"],
    "바위": ["가위", "도마뱀"],
    "보": ["바위", "스팍"],
    "도마뱀": ["스팍", "보"],
    "스팍": ["가위", "바위"],
}
RESULT_TEXT = ["비김", "이김", "짐"]

def make_table(choices, beats):
    """BEATS 딕셔너리로 판정표 TABLE[나][컴퓨터] (0 비김, 1 이김, 2 짐)를 만든다"""
    table = []
    for me in choices:                      # 행: 나
        row = []
        for cpu in choices:                 # 열: 컴퓨터
            if me == cpu:
                row.append(0)
            elif cpu in beats[me]:
                row.append(1)
            else:
                row.append(2)
        table.append(row)
    return table

TABLE = make_table(CHOICES, BEATS)

def get_pick():
    """올바른 선택이 들어올 때까지 다시 묻고, 인덱스를 돌려준다"""
    while True:
        pick = input("가위/바위/보/도마뱀/스팍 > ").strip()
        if pick in CHOICES:
            return CHOICES.index(pick)
        print("다섯 가지 중에서 입력하세요!")

def play_match(win_goal=2):
    """먼저 win_goal승 하면 끝나는 한 경기. 기록표와 승리 여부를 돌려준다"""
    score = {"이김": 0, "짐": 0, "비김": 0}
    records = []                            # [[라운드, 나, 컴퓨터, 결과], ...]
    while score["이김"] < win_goal and score["짐"] < win_goal:
        me, cpu = get_pick(), random.randrange(len(CHOICES))
        result = RESULT_TEXT[TABLE[me][cpu]]
        score[result] += 1
        records.append([len(records) + 1, CHOICES[me], CHOICES[cpu], result])
        print(f"나: {CHOICES[me]} vs 컴퓨터: {CHOICES[cpu]} → {result}")
    return records, score["이김"] == win_goal

def print_records(records):
    """기록표를 중첩 반복문으로 출력한다"""
    for row in [["라운드", "나", "컴퓨터", "결과"]] + records:
        for item in row:
            print(f"{item!s:<5}", end="| ")
        print()

def run_tests():
    """판정표가 규칙에 맞는지 자동으로 검사한다"""
    n = len(CHOICES)
    for a in range(n):
        assert TABLE[a][a] == 0, "같은 선택은 비김이어야 함"
        assert TABLE[a].count(1) == 2 and TABLE[a].count(2) == 2, "각 선택은 2개를 이기고 2개에게 져야 함"
        for b in range(n):
            if a != b:
                # 대칭성: a가 b를 이기면(1) b는 a에게 진다(2)
                assert {TABLE[a][b], TABLE[b][a]} == {1, 2}, (CHOICES[a], CHOICES[b])
    assert RESULT_TEXT[TABLE[CHOICES.index("스팍")][CHOICES.index("가위")]] == "이김"
    print("판정표 테스트 통과!")
    for name, row in zip(CHOICES, TABLE):
        print(f"{name:<4}", row)

def main():
    print("=== 5가지 가위바위보 === 먼저 2승 하면 이깁니다!")
    while True:
        records, won = play_match()
        print_records(records)
        print("최종 승리!" if won else "아쉽게 패배...")
        if input("또 할까요? (y/n) > ").strip().lower() != "y":
            break

if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "test":
        run_tests()
    else:
        main()
```
